# Moonlit Courtyard · 桂月庭

一个使用 Three.js 构建的可交互中秋赏月 3D 网页。左侧石拱桥、右侧临水亭、后方桂花树与中式院墙，前景荷塘和岸石，天空是明亮满月。

参考：[抖音庭院赏月视频](https://www.douyin.com/video/7689126213884890414)。开发前已在抖音桌面版观察画面和动态效果；本项目使用自行编写的几何体、程序材质与特效，不包含视频素材或视频中的源码。

## 启动

需要 Node.js 20.19+ 或 22.12+，建议 Node.js 24 LTS。

```powershell
cd "D:\Codex_Demo\Moonlit Courtyard"
npm install
npm run dev
```

打开终端显示的 Local 地址，默认是 `http://localhost:5173`。若 PowerShell 阻止执行 npm.ps1，可使用 `npm.cmd install` 和 `npm.cmd run dev`，不需要修改系统执行策略。

手机预览：电脑和手机接入同一局域网，手机访问 `http://电脑局域网IP:5173`。开发服务器监听 `0.0.0.0`；仅在可信局域网使用。浏览器需要支持 WebGL 2。

首次安装需要联网。安装后开发、构建和庭院本身都不需要从外部 CDN 获取图片、字体、模型或音频。

## 构建与预览

```powershell
npm run build
npm run preview
```

生产文件位于 `dist/`，可部署到静态网站托管服务。通过 HTTP 服务访问，不能直接双击 `index.html`。`npm run preview` 默认端口为 `4173`。

## 交互

| 操作 | 作用 |
| --- | --- |
| 鼠标拖动 / 单指滑动 | 旋转观察庭院 |
| 滚轮 / 双指捏合 | 缩放视角 |
| 点击 / 轻触天空 | 升起并绽放烟花 |
| 点击 / 轻触水面 | 锦鲤跃出，落水时泛起水花和涟漪 |
| 点击 / 轻触桂花树叶 | 树枝摇曳，一簇叶子随风落下 |
| 月光、灯火、水雾滑块 | 实时调节氛围 |
| 赏月 / 临水 / 入亭 | 切换观景位置 |
| 回到初见 | 重置视角，保留氛围设置 |
| 右上角声音按钮 | 开启 / 关闭本地生成的水声与虫鸣，默认静音 |
| 右上角全屏按钮 | 进入 / 退出全屏，取决于浏览器支持情况 |

手机上的氛围面板默认收起，点击“此刻的庭院”展开。系统启用减少动态效果时，场景动画减速，视角切换取消过渡。

浅水中有常驻的小锦鲤游动，水面保留月色和灯笼倒影。轻盈画质减少游鱼数量。

## 画质与性能

- `自动适配`：桌面从精致开始，触屏设备从均衡开始；连续低帧率时自动降低画质。
- `精致`：完整桂花树、实时反射、阴影和柔和辉光，像素比最高 1.8。
- `均衡`：减少植被与粒子，反射每两帧更新，像素比最高 1.3。
- `轻盈`：关闭阴影与辉光后处理，反射每三帧更新，减少植被与粒子，像素比为 1。
- 植被、桂花、岸石和芦苇使用 InstancedMesh 合并绘制；反射贴图在桌面为 1024×1024、触屏为 512×512。
- 页面隐藏时暂停渲染与环境音。帧率依赖设备与浏览器，不保证每台手机达到固定帧率。

## 源码结构

```text
index.html              页面结构与可访问的控制面板
src/main.js             渲染、相机、灯光、交互、画质与生命周期
src/architecture.js     庭院、亭子、石桥、茶桌与灯笼
src/nature.js           桂花树、桂花、竹子、荷叶、荷花与岸石
src/atmosphere.js       天空、月亮、薄雾、粒子与涟漪着色器
src/fireworks.js        点击天空的烟花与可复用粒子池
src/fish.js             浅水游鱼、点击锦鲤跃出与水花
src/picking.js          可见表面的点击判定与遮挡处理
src/textures.js         本地生成石材、木纹、瓦片、月面与水面法线
src/geometry.js         几何体创建工具
src/audio.js            可选的 Web Audio 环境音
src/style.css           响应式界面与移动端布局
public/moon.svg         网站图标
vite.config.js          构建时拆分 Three.js 核心与扩展，便于缓存
```

水面使用 Three.js Water 的平面反射和动态法线；低雾使用多层噪声着色器。没有物理流体模拟或体积路径追踪，以便兼顾浏览器画质和性能。

## 排查

- 页面提示无法启动 3D：更新浏览器，检查硬件加速及 WebGL 2 支持。
- 设备发热或掉帧：切换到“轻盈”，或保持“自动适配”。
- 手机没有全屏：部分移动浏览器不支持 Fullscreen API，可正常使用其他交互。
- 安装超时：检查网络，可临时使用 `npm install --registry=https://registry.npmmirror.com`；不必修改全局 npm 设置。

依赖：Three.js 0.180.0、Vite 7.1.7。API 文档：[Three.js](https://threejs.org/docs/)。
